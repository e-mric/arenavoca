# Bundled typefaces

- Atkinson Hyperlegible: interface controls and metadata; existing OFL.txt.
- Libre Baskerville variable: bold Spanish and English card sentences; LibreBaskerville-OFL.txt. Downloaded 17 October 2026 from https://github.com/google/fonts/tree/main/ofl/librebaskerville . Served locally and loaded before card rendering, including Spanish accents. No runtime font-service request.

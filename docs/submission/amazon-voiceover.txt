What if watching football could help you practise Spanish, one moment at a time?

This is ArenaVoca, running on Amazon's Vega simulator. It connects optional language practice to the action you are watching.

The match takes the full screen. For this demonstration, we use an original illustrated football sequence, with three prepared learning moments: a pass, a shot, and a save.

After the pass, a moment becomes available. Nothing opens automatically. Using the remote, I choose the moment when I am ready.

The Spanish phrase describes the action: El jugador pasa el balón. I can reveal English underneath: The player passes the ball. The video keeps moving, and my selected card stays in place.

I can save this phrase, then return to full-screen watching with Back. The other moments become available as the sequence reaches them. Learning stays optional throughout.

Later, Saved brings me back to the phrases I chose. Practise asks me to recall the meaning. An incorrect answer gives feedback, and I can try again.

Saved cards and playback position stay on this device. When I reopen the app, it restores the position with playback paused, so I decide when to continue.

The TV app uses React Native with Amazon's Kepler framework, its media player, and local storage. The video's position controls which moments are available. Opening a learning card never sends a pause or seek command.

This prototype uses prepared content. It does not claim live match recognition or phone synchronisation. The working loop is simple: watch an action, understand its Spanish, and practise remembering it.

ArenaVoca. Watch. Notice. Remember.
